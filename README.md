## 🚀 How to Build and Run

### 1. Running Spring Boot Backend Projects

Navigate to any backend project root (e.g., `Deepskill Spring REST Spring` or `LibraryManagement`):

```bash
# Clone the repository
git clone [https://github.com/ASHWINs-HUB/cognizant-deepskilling.git](https://github.com/ASHWINs-HUB/cognizant-deepskilling.git)

# Navigate to the target Spring Boot module
cd "Deepskill Spring REST Spring"

# Clean and package the application
mvn clean install

# Launch the Spring Boot application
mvn spring-boot:run

```

### 2. Running Frontend Projects

#### **React Applications (`REACT LIBRARY LMS PORTAL`)**

```bash
cd "REACT LIBRARY LMS PORTAL/Deepskill"
npm install
npm run dev   # or: npm start

```

#### **Angular Applications (`Angular/student-course-portal`)**

```bash
cd "Angular/student-course-portal"
npm install
ng serve

```
